TODO. 大数据实战运用
- 大数据文件的"读取"本身并不适合多线程并发读取(IO争抢)
- 大数据的"解析和存储"通常才是性能关键

不拆分文件:
  - 同步读取数据, 并发处理和持久化    => 最佳实践
  - 偏移并发读取, 并发操作各个部分数据 => 必须预先建立索引划分(耗时)
拆分文件:
  - 单机多线程并发处理每个Split文件 => 必须预先处理分片(增加IO扫描)
  - 多机分布式处理每个Split文件    => 对切分文件进行分发

当每个Item数据格式统一且大小标准时: 按文件大小均分最佳(10GB, 45S) => 只扫描一遍文件
当每个Item数据格式统一但大小随机时: 按平均数量大小均分最佳, 利于并发存储和和解析 => 需扫描两遍文件
